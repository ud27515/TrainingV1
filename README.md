# 魔導書のアトリエ — 0.15

中学生と家族が、それぞれのスマホで学ぶ静的Webアプリです。修練による本人レベル、呪文コレクション、取り組みポイントを持ち、記録の見せ合いとお小遣いの受け渡しは対面で行います。英検・対外模試の対策は別アプリの範囲です。

## 使い始める

`index.html` が必要な教材・コードを内包する一ファイル版です。PCでは展開後にブラウザで開けます。スマホのファイルプレビューはJavaScriptや保存が使えない場合があるため、継続利用はGitHub Pagesの同じURLを同じブラウザで開いてください。

公開する場合は、このZIPを展開した内容をリポジトリに置き、GitHub Pagesの公開元をそのブランチのルートに指定します。ビルドサービスや外部APIは不要です。既存アプリを残す場合は別リポジトリを使ってください。この成果物は公開前のファイル一式で、GitHubへのアップロード・公開は行っていません。

手順の参照： https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 画面と学習の流れ

- ホーム：次に取り組む候補、本人レベル、週間・累計・交換残高。
- 知識の書庫：教科、サブ科目、学年目安、キーワード、復習候補、テスト範囲で絞り込み。
- 単元の入口：短い説明、つながる基礎、自力で確かめた考え方、任意の未習申告とテスト範囲指定。
- 修練：解く／見破る／読み解く／組み立てるを組み合わせた最大3課題。途中保存と再開、ヒント、誤答解説の確認。
- 魔導書：獲得済み呪文と未解明の手がかり。新しい呪文を中心に表示し、続きを開けます。条件は本書に記載しません。
- 家族に見せる：レベル、今週の取り組み、最近獲得した呪文。
- 記録・設定：表示名、バックアップ・復元、旧版履歴保管、交換済みポイントの記録。

装備機能と詠唱・発動アニメーションはありません。

## 出題と評価

テスト範囲の指定、復習の時期、基礎の確認状況から候補を選びます。ヒントや未習説明を使った正解は自力正解と区別します。復習間隔は直近の誤答・支援利用と、日を置いた自力正解の蓄積から1・3・7日の簡易規則で選びます。これは学力の確定診断ではありません。

固定問題は直近24時間の同一出題を避けます。使い切った単元では別単元や別の考え方へ案内します。追加した86単元は各4問の入口教材なので、同じ単元だけを長時間続ける用途には足りません。一次方程式も同じ型の内部は数値変更です。「似た問題で飽きさせない」という構想の完成には、問題構造・素材・難度のさらなる追加と実使用評価が必要です。

学校別の全範囲・私立進学校の発展問題を網羅した完成教材ではありません。説明も短く、段階的な授業、自由記述の採点、図形の作図、リスニングには未対応です。「組み立てる」も選択式や穴埋め式です。教材の専門家レビューは未実施です。

## ポイントとレベル

完了したセットの課題1件につき1pt（通常3課題で3pt）を付与します。正誤・ヒントによる減額はなく、一日の上限・獲得量の逓減もありません。中断してセットを終了した場合は回答記録を残しますが、未完了セットのポイントは付きません。

本人レベルは取り組みの累積経験値によって上がり、学力や正答率を表しません。経験値は課題1件につき10XPで積み上がります。ポイントと経験値は分けて管理します。ポイントを交換してもXP・レベル・累計獲得・週間獲得は減りません。週間集計は日本時間の月曜始まりです。お小遣い換算レートは未設定です。

家族内の比較は同じポイント規則を使いますが、問題ごとの所要時間や負担が同一とは限りません。レートを決める前に実際の取り組み方を見て調整できます。

## 保存と移行

保存先は端末のブラウザ内、キーは `study-trail-v1` です。ログインやサーバー、端末間同期はありません。一つのブラウザでは一人用です。保存不能時は画面に通知します。容量制限、ブラウザのデータ削除、端末変更に備えて定期的にバックアップしてください。記録はlocalStorageに保存し、容量無制限ではありません。

0.1〜0.14の記録・ポイント・獲得済み呪文を引き継げます。同じURLとブラウザなら継続でき、別URLや端末へ移す場合はJSONを書き出して復元します。旧版の `midterm2026-v2` は変更しません。旧版バックアップは原履歴として保管し、新ポイントや理解判定へ自動換算しません。

別タブからの更新は取り込みますが、同時編集の完全な競合解決はありません。一つのタブで利用してください。家族内の信頼を前提としたポイントで、改ざん防止や支払い機能はありません。

## 0.5：一次方程式の先行実装

- 計算、等式の操作、誤り発見、立式、検算、条件不足や矛盾を組み合わせる固定13問＋11生成ルール。
- 通常の3課題は異なる3構造を選び、可能な範囲で思考操作も切り替えます。同じ構造の連続を避け、直近8課題では同構造2回まで。学び方を限定した場合は、候補不足で止まらないよう頻度制限を緩めますが、同構造の連続は避けます。
- 未確認の項目や再確認候補を出題で優先。7つの項目ごとに、異なる型の自力正解と日を置いた確認を表示します。単元全体の習得完了や、記述・説明力の認定はしません。
- 整数・小数・分数を有理数として比較。全角やマイナス記号も処理し、入力形式が不明な場合は誤答にせず入力を案内します。式の自由入力は実行しません。
- 段階ヒントと未習向けの基本例。利用記録を保持し、自力の証拠とは分けます。
- 各生成器441パラメータ、計4,851通りを独立した式で検証。これは問題の多様性を4,851構造と数える意味ではありません。
- 新テスト9項目＋既存20項目。100セットの自動出題、数値採点、ヒント・旧記録・保存の互換を確認。ブラウザでも入力形式エラー、分数の同値採点、段階ヒントと再読み込みを確認しました。

## 0.15：ポイント獲得レートの変更

今後完了する通常3課題セットは3pt（1課題あたり1pt）です。1・2課題の短いセットは1・2pt。日次上限や逓減はありません。正誤・ヒント利用で減額しません。

未リリースの試作品から移るときだけ、旧ポイント残高と交換履歴をリセットします。学習履歴・獲得済みコレクション・経験値は保持します。一度移行した記録には識別情報を残し、再読込・バックアップ復元・今後の教材更新で繰り返しリセットしません。経験値は従来どおり1課題10XP、ポイントとは別に記録します。

ポイント変更の検証は通常セット3pt/30XP、短いセット1pt/10XP、旧台帳リセットと学習記録保持、移行済み記録の再復元、無効XPを対象にしています。お小遣い換算レートは引き続き未設定です。

運用方針は、全課程の教材完成を待たず初回版をリリースし、同じ公開URLで教材を追加更新する方式です。学習ログと教材を分け、旧問題ID・当時の回答内容を保持して更新します。ブラウザの保存領域を消した場合や機種変更時はファイルのバックアップ・復元が必要です。公開先の確定とリリース時の画面確認は未完了です。
