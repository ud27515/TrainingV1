# 魔導書のアトリエ：全課程設計と教材・出題の品質基準

設計版1.0／2026年10月24日

## 今回の成果と適用範囲

既存91単元を学習目標に分解し、音声・発話・英文記述・国語の対話、および数学の発展分野を別枠で追加した。設計は97単元・586学習項目。各項目を「何ができるか」で記述し、教科ごとに基礎・活用・転用の到達目標を定義した。

これは教材を586項目分実装したという意味ではない。既存376問を各項目へ対応付ける作業、各学習項目の前提知識の精査、指導要領の項目単位の突合は未完了である。現行アプリ0.4の問題・ポイント・保存形式は変更していない。今回の成果は、次の教材制作とエンジン改修に使う設計・品質基準・検証用見本である。

| 成果物 | 役割 |
| --- | --- |
| curriculum-map.md | 全学習項目の閲覧用一覧 |
| curriculum-design.json | 単元・学習項目・到達水準・前提知識を実装へ渡すデータ |
| quality-policy.json | 品質ゲート、多様性、理解度判定、ポイントの規則案 |
| pilot-examples.md / pilot-items.json | 一次方程式を中心とした、構造の異なる見本12問 |
| validate_design.py | ID・参照・循環・形式・数値解等の機械検証 |

## 1. 全課程の境界

「一般的な私立中学進学校」に統一された全課程が存在するとは仮定しない。中学校の共通内容を基盤に、学校によって先取りや発展が異なる層を重ねる。本人には学年順を強制しない。

1. 共通内容：5教科の知識、技能、読解、説明、資料活用を対象にする。
2. 発展内容：複合条件・未知場面・証明・記述を深める。同じ用語でも深さを区別する。
3. 学校固有内容：教材作品、試験範囲、授業独自の扱いを後から対応付けられるようにする。日々の進度申告は必須にしない。
4. 高校内容の先取り：中学内容と混ぜて既習と推定せず、別の拡張として追加する。現設計は高校全課程を含まない。

数学は代数／幾何、英語は文法／コミュニケーション、国語は文法・古典／現代文・語句、理科は物理・化学／生物・地学、社会は地理／歴史／公民で表示する。国語2・国語3などの表示名は学校向けの別名として保持する。数学の統計・確率は現UIでは代数側に置くが、内部領域はデータの活用として分離する。

文部科学省の各教科解説を領域の参照に使った。例えば国語の話す・聞く活動、数学のデータ活用、外国語の音声・発信を「選択問題で代用して測定済み」にしない。ただし、指導要領への全項目対応表や、学校別の網羅性を保証した状態ではない。

## 2. 学習項目と到達水準

単元は画面上の入口、学習項目は測定の単位とする。例えば「一次方程式を理解した」という一つの値にはしない。

| 一次方程式の学習項目 | 基礎の証拠 | 活用・転用の証拠 |
| --- | --- | --- |
| 等式の性質 | 両辺に行う同じ操作を選び理由を述べる | 誤った変形の最初の箇所を特定し修正する |
| 解法 | 基本形を解く | 括弧・分数・両辺の未知数に合う手順を選ぶ |
| 検算 | 代入して左右を確かめる | 数として正しい解が文脈でも使えるか判断する |
| 立式 | 未知数の対象と単位を定める | 表・文章・移動から関係式を作る |
| 条件の吟味 | 与えられた条件を列挙する | 不足・矛盾・複数の解釈を根拠付きで指摘する |

586項目は初期の粒度である。複数の独立した誤りが同じ項目に混ざる場合は分割する。単なる同義語の言い換えでは項目を増やさない。漢字・英単語は別途語彙台帳を持ち、領域としての項目数と個々の語彙数を混同しない。

前提知識には「理解に必要」「練習があると楽」「横断的につながる」を区別する余地を持たせる。現JSONの単元リンクは推奨の基礎で、必須の解放条件ではない。学習項目単位のリンクは一次方程式の7項目を先行設計し、残りは未精査と明示した。

## 3. 問題バンクと生成エンジンの分担

両方を用いる。品質を決めるのは「検証済みの問題構造」であり、毎回自由生成する文章ではない。

| 内容 | 制作方式 | 検証 |
| --- | --- | --- |
| 計算・数量・表・座標 | 制約付き生成 | 解を独立計算し、境界・一意性・表示を検証 |
| 読解・歴史資料・実験の考察 | 素材と設問を組にした編集済みバンク | 素材の充足、根拠、別解、権利を点検 |
| 誤り発見 | 誤概念を意図した問題構造 | 誤り箇所が一意か、他の手順は正しいか検証 |
| 記述・証明・発話 | 採点観点と例答付きバンク | 意味上の許容範囲と部分点を人がレビュー |

制作時にAIを使うことはできるが、未レビューの出力を学習者へ直接出さない。GitHubで動くアプリ内にAPIキーを置かない。自由記述の意味採点を静的アプリだけで完全自動化したとは扱わない。

問題データは、ID・版・対象スキル・主評価スキル・構造ID・思考操作・提示形式・水準・前提知識・正答仕様・誤概念・段階ヒント・解説・出典・レビュー状態を保持する。生成ではさらに、パラメータ範囲・禁止条件・独立した検算器を持つ。

同じ構造の数字・人名・品物を変えても構造IDは同じ。素材の違いは素材ID、解くための関係の違いは構造IDとして分ける。「solve/detect/connect/create」というUIの4ラベルだけで多様性を認定しない。

## 4. 飽きを避ける出題規則

次の数値は検証済みの学習理論ではなく、試用で調整する初期設定である。

- 通常の5課題セットは、3構造以上・2種類以上の思考操作を含む。
- 同じ構造を連続させず、直近8課題中の同構造は原則2課題まで。
- 直近30課題に同一問題を自動で再投入しない。直後の訂正は学習支援として別扱いにする。
- 別の単元でも計算の形が同じなら、上位の構造タグで反復を検知する。
- 必要な多様性を満たせなければ、隣接スキル・別単元を提示する。教材不足を数字違いで隠さない。
- 本人が復習を希望した場合は、再挑戦と分かる表示で同じ内容を選べる。日次ポイント上限にはしない。直後の再正解を新しい理解の証拠にはしない。

単元を変えることだけで飽きを解決しない。本人が一つの単元を深めたいときに十分な構造を提供する必要がある。教材制作の目標は各学習項目2構造以上、主要単元全体6構造以上を仮の下限とするが、数だけを満たして合格にはしない。10セットの出題シミュレーションと実使用で偏りを点検する。

## 5. 選択肢・問題文の品質ゲート

現在の問題バンクにも、この基準を満たさないものがある。現行問題は採用済みとみなさず、レビュー待ちへ戻して分類する。

| 不合格例 | 問題点 | 修正方針 |
| --- | --- | --- |
| 海の名前を問うのに山脈や年号を混ぜる | 語の種類だけで消去できる | 同地域の海など同種の候補にそろえる |
| 正解だけ長く丁寧で、誤答は「必ず」「全部」 | 文体が正解を漏らす | 文体・長さをそろえ、誤答に具体的根拠を持たせる |
| 地理や公民の誤答に明らかに無関係な物を置く | 内容理解を測れていない | 実際の混同、因果の逆、分母の取り違え等から作る |
| 本文なしで作品中の心情を聞く | 暗記や外部教材を前提にする | 必要な本文を提示し、根拠範囲を定める |
| 「隠れている時間」と「渡り終える時間」を曖昧に扱う | 数量関係が変わる | 開始・終了の位置を明示し、必要なら図を付ける |
| 知識を選ぶだけの問題を「組み立てられた」と判定する | 測定対象と回答形式がずれる | 選択で測れる範囲と、生成・記述で測る範囲を分ける |

選択肢は3択でもよい。4択のために不自然な誤答を追加しない。各誤答に対応する誤概念を記録するが、一回の選択だけで「その誤概念がある」と断定しない。

公開前には①素材と条件の充足、②独立した正答検証、③同種で妥当な誤答、④文体等の漏洩防止、⑤理由のある解説、⑥生成制約、⑦選択肢だけの盲検、⑧図・音声の整合、⑨出典・権利・時点、⑩構造の重複を確認する。機械テストでは③④⑦の意味上の妥当性を保証できないため、人のレビューを公開条件として残す。

## 6. 理解度と学校の進度を別管理する

学校での状態は「不明／未習の申告／既習の申告」。不明を未習と扱わず、正解したことを学校で習った証拠にもしない。

理解の記録は学習項目ごとに、以下の証拠を保持する。

| 状態 | 暫定的な判定規則 |
| --- | --- |
| 未確認 | 評価できる解答がまだない |
| 支援ありで取り組み中 | ヒント・説明を使った。学習として評価するが自力とは分ける |
| 自力の証拠あり | ヒントなしで異なる2構造に正解 |
| 日を置いて確認 | 自力の証拠に加えて2日以上後、未使用の別構造に自力正解 |
| 転用の証拠あり | 日を置いた確認に加え、未知の転用問題2構造で理由を含めて確認 |

これらの閾値は初期設計値で、心理測定として妥当性検証済みではない。「習得率87%」のような精密さを装った数字は出さない。選択問題だけで説明力・記述力・会話力を認定しない。

複合問題を最終答案だけで正解しても、対象スキル全部へ一律に加点しない。途中の証拠がない場合は主評価スキルだけを更新する。誤答一回で過去の実績を消さず、再確認が必要という印を追加する。放置期間だけでレベルや呪文を取り上げない。

時間は難度調整の補助情報にとどめ、中断や慎重な思考を不利にしない。解答速度でポイントや理解を判定しない。

## 7. 出題の流れと未習支援

初回に長い一斉診断を強制しない。本人が選んだ単元や短いおまかせセットから始める。入口問題で十分な証拠が得られた範囲は進め、証拠のない周辺まで既習と推定しない。

候補は、本人の選択を最優先に、指定した試験範囲、復習時期、直近のつまずき、基礎とのつながりから集める。その後で多様性規則を適用する。「弱点だから」と同じ型を続けることはしない。

未習の申告時は、①短い概念説明、②解き方を示す例、③支援付き練習、④素材や構造を変えた自力確認へ進む。ヒントは、注目点→関係の整理→途中手順の順に出す。答えを見た直後の再入力は練習記録であって、自力の証拠ではない。

誤答時は理由を確認し、可能なら間違えた手順を一つ修正する。正解するまで無限に閉じ込めず、「説明を読んで先へ」を許す。ポイントの対象となる完了と、理解度の証拠を分ける。

## 8. 採点とデータ構造

| 回答形式 | 採点方法 | 不確かな場合 |
| --- | --- | --- |
| 数値・分数・単位 | 安全な構文解析と同値比較。文字列のevalは使わない | 入力形式を案内し、不正解と決めつけない |
| 選択・並べ替え | 検証済み正答集合 | 設問不備を報告できるようにする |
| 英語短文 | 許容表記・同義の範囲を明示した規則 | 自由表現は自動判定外とする |
| 記述・証明 | 観点別の例答と部分点。確実な範囲のみ自動判定 | 自己確認／家族確認を別種の証拠として保存 |
| 発話 | 音声素材と振り返り。録音の権限は利用時に任意で求める | 発音や会話能力をテキスト選択から推定しない |

学習履歴は、問題IDと版、生成パラメータ、解答、初回／再挑戦、使ったヒント段階、採点器の版、スキル別の観察証拠、時刻を追記する。推定状態は履歴から再計算できるようにする。教材更新で問題が消えても過去の記録を壊さない。

既存バックアップの記録に新しいスキルを無理に割り当てない。対応を確かめた項目だけ移行し、不明分は旧記録として表示する。ポイント台帳と学習証拠台帳は分離し、理解度の判定規則を変えても過去の獲得ポイントは変えない。

語彙一覧、読解素材、問題、構造、採点器、出題履歴を分けて管理する。ローカル保存は長期利用前にIndexedDBへの移行とバックアップ検証を行うが、この設計版では未実装である。

## 9. 報酬との接続

日次上限なし、獲得量の逓減なし、正答率・速さによる加点なしを維持する。レベルは取り組み、学習状態は理解の証拠、コレクションは発見として扱う。

現在は1課題10pt。記述や実験設計を追加すると課題負担が違うため、制作時に「標準的な作業のまとまり」を定め、短い選択の大量連打だけが有利にならないようにする。実時間の長さで報酬を決めず、教材側の工程を基準とする。工程を細かく分けてポイントを水増しすることも避ける。配点変更は家族試用後に行い、過去に獲得した分を減らさない。

隠し条件の具体的な内容は本資料に含めない。学習イベントの版変更で獲得済みコレクションが失われないことを試験する。お小遣い換算レートは最後に決める。

## 10. 次の制作単位と終了条件

最初の制作単位は「一次方程式：等式の性質→解法→立式→条件確認」。子どもが既に触れている分野で、計算の生成と読解・誤り発見を比較できるためである。見本12問をたたき台として、ここで多様性・採点・測定の品質を固める。

| 順番 | 実作業 | 終了条件 |
| --- | --- | --- |
| 1 | 既存問題をスキルと構造へ対応付け、基準外を隔離 | 採用理由・不採用理由・測定対象が全件で明確 |
| 2 | 7学習項目の教材と段階ヒントを制作 | 各項目で基礎・活用を測れ、必要な説明がある |
| 3 | 生成器と採点器を実装 | 全パラメータ、境界値、別解、単位を検証 |
| 4 | 出題と理解度記録を実装 | 同型反復・支援正解・旧記録の誤認を回帰テストで防ぐ |
| 5 | 10セット相当の出題を確認 | 多様性規則を守り、教材切れ時の動作が明示される |
| 6 | スマホで家族試用 | 不明瞭な問題、誤採点、保存不具合を解消し、飽きた理由を収集 |
| 7 | 他分野へ展開 | 国語・資料読解など異なる性質の教材でも同基準を満たす |

見本12問だけで7項目の必要量を満たしたとは扱わない。特に音声・自由記述・図形では個別の品質確認が必要であり、数学の成功をそのまま全教科の完成としない。
